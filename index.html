Data Engineering & Analytics Architecture

Alur Transformasi Data: Dari Transaksi Mentah ke Metrik Bisnis

Berikut adalah kueri SQL dan skrip Python yang digunakan untuk mentransformasi ledger transaksi mentah NexaMart menjadi metrik segmentasi RFM dan matriks kohor retensi bulanan yang siap dikonsumsi manajemen.

PostgreSQL: Kueri Segmentasi RFM Menggunakan NTILE(5) 
-- ===================================================================
-- PROYEK: NexaMart Customer Segmentation (Metode RFM)
-- TUJUAN: Menghitung Recency, Frequency, Monetary & Kategori Segmen
-- ===================================================================

WITH customer_summary AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_purchase_date,
        MAX(order_date) AS latest_purchase_date,
        -- Recency: Selisih hari dari transaksi terakhir ke tanggal referensi
        ('2024-06-30'::DATE - MAX(order_date)::DATE) AS recency_days,
        -- Frequency: Total jumlah transaksi unik
        COUNT(DISTINCT order_id) AS frequency,
        -- Monetary: Akumulasi nilai belanja kotor
        SUM(total_amount_idr) AS monetary_value
    FROM nexamart_orders
    WHERE order_status = 'COMPLETED'
    GROUP BY customer_id
),
rfm_scoring AS (
    SELECT
        customer_id,
        recency_days,
        frequency,
        monetary_value,
        -- NTILE(5): Membagi distribusi pelanggan menjadi 5 kuantil sama rata
        NTILE(5) OVER (ORDER BY recency_days DESC) AS r_score,
        NTILE(5) OVER (ORDER BY frequency ASC) AS f_score,
        NTILE(5) OVER (ORDER BY monetary_value ASC) AS m_score
    FROM customer_summary
)
SELECT
    customer_id,
    recency_days,
    frequency,
    monetary_value,
    CONCAT(r_score, f_score, m_score) AS rfm_combined_score,
    CASE
        WHEN r_score >= 4 AND f_score >= 4 THEN 'Champions'
        WHEN r_score >= 3 AND f_score >= 3 THEN 'Loyal Customers'
        WHEN r_score >= 3 AND f_score <= 2 THEN 'Potential Loyalist'
        WHEN r_score <= 2 AND f_score >= 3 THEN 'At Risk'
        ELSE 'Lost'
    END AS customer_segment
FROM rfm_scoring
ORDER BY monetary_value DESC;
Python (Pandas): Transformasi Data Transaksi Menjadi Matriks Kohor 
import pandas as pd
import numpy as np

# 1. Muat data riwayat transaksi
df = pd.read_csv('nexamart_orders.csv', parse_dates=['order_date'])

# 2. Definisikan bulan transaksi dan bulan pertama kali akuisisi (Kohor)
df['order_month'] = df['order_date'].dt.to_period('M')
df['cohort_month'] = df.groupby('customer_id')['order_month'].transform('min')

# 3. Hitung indeks bulan retensi (0 = M0, 1 = M1, ...)
def calculate_cohort_index(df):
    year_diff = df['order_month'].dt.year - df['cohort_month'].dt.year
    month_diff = df['order_month'].dt.month - df['cohort_month'].dt.month
    return year_diff * 12 + month_diff

df['cohort_index'] = calculate_cohort_index(df)

# 4. Agregasi pelanggan unik per kohor dan indeks
cohort_pivot = df.groupby(['cohort_month', 'cohort_index'])['customer_id'].nunique().reset_index()
retention_matrix = cohort_pivot.pivot(index='cohort_month', columns='cohort_index', values='customer_id')

# 5. Normalisasi persentase retensi relatif terhadap Bulan ke-0 (M0)
cohort_sizes = retention_matrix.iloc[:, 0]
retention_rate_pct = retention_matrix.divide(cohort_sizes, axis=0) * 100

print("=== MATRIKS RETENSI KOHOR BULANAN (PERSENTASE %) ===")
print(retention_rate_pct.round(1))

Cara Replikasi Segmentasi RFM di Excel / Google Sheets

1. Recency: Gunakan rumus =DATEDIF(MAX(Tanggal_Transaksi_Customer), TODAY(), "d").

2. Frequency: Gunakan rumus =COUNTIF(Kolom_Customer_ID, ID_Tertentu).

3. Monetary: Gunakan rumus =SUMIFS(Kolom_Total_Belanja, Kolom_Customer_ID, ID_Tertentu).

4. Skor Kuantil: Manfaatkan rumus =PERCENTRANK() dikombinasikan fungsi IF() bertingkat untuk memberi bobot skor 1 hingga 5.

Formula Penting Spreadsheet (Excel / Google Sheets)

1. Klasifikasi Status Churn: =IF(D2 > 60; "CHURN"; "AKTIF")

Di mana sel D2 berisi Recency (jumlah hari sejak transaksi terakhir).

2. Menghitung Total Omzet per Kanal: =SUMIFS(F:F; C:C; "Google Search")

Menjumlahkan kolom F (Monetary) untuk baris kanal tertentu.

3. Lookup Segmentasi Berdasarkan Skor: =VLOOKUP(G2; Tabel_Kategori_RFM; 2; FALSE)

Mengambil nama segmen dari tabel referensi skor RFM.
